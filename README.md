# 노선 일조 시뮬레이터 · 웹 버전

PC 브라우저에서 KTX 시간표를 따라 햇빛 방향을 계산합니다. HTML/CSS/JavaScript만 사용하는 정적 웹사이트이며 별도 계산 서버, Python 설치, 외부 CDN이 필요하지 않습니다. 업로드한 지도와 작업 파일은 브라우저에서만 처리합니다.

## 실행

이 폴더에서 다음 명령을 실행한 뒤 `http://127.0.0.1:8765/`를 엽니다.

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

`index.html`을 더블클릭하는 `file://` 방식은 데이터 읽기와 작업자 실행이 제한됩니다. 로컬 웹 서버 또는 GitHub Pages 주소로 접속하세요.

## GitHub Pages 게시

대상 저장소: `megabyte-forge/railway-sunlight`

1. `megabyte-forge` 계정으로 새 `railway-sunlight` 저장소를 만듭니다.
2. **이 폴더 안의 파일과 assets 폴더**를 저장소 최상위에 올립니다. `index.html`이 저장소 최상위에 있어야 합니다.
3. 저장소 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**, `main`, `/(root)`를 선택하고 저장합니다.
4. 게시가 완료되면 `https://megabyte-forge.github.io/railway-sunlight/`에서 사용할 수 있습니다.

모든 파일 경로는 상대 경로이므로 GitHub Pages의 저장소 하위 주소에서도 동작합니다. 이 문서에 적힌 주소는 배포 예정 주소이며, 파일 업로드와 Pages 설정을 완료해야 접속할 수 있습니다.

## 주요 기능

- 한국 표준시 기준 오늘 날짜, YYYYMMDD 직접 입력 및 달력 선택
- 선택한 요일에 운행하는 열차만 표시, 출발시각순 정렬
- 출발역·도착역 복수 체크 및 전체 선택/해제, 단일 역 필터 숨김
- 왼쪽 분석 / 중앙 지도 / 오른쪽 구간표, 너비 조절과 하단 재생 막대
- 표 우클릭으로 표시 열 선택, CSV 다운로드
- 정차역 시각과 거리 비례 보간, 양방향 수서–동탄–평택지제 터널 처리
- 사용자 이미지 업로드, 색상 기반 노선 감지와 경유점 추출, 수동 편집, 기준점 3개를 이용한 위치 보정
- 시간표 작업 파일 저장/불러오기: 기존 데스크톱 v2 작업과 호환
- 직접 경로 저장/불러오기: 웹 v3 형식으로 저장하며, 기존 데스크톱 v1 사용자 지도 작업 파일도 가져올 수 있습니다.

계산은 Web Worker에서 수행합니다. 시간 막대는 출발 정시부터 4~5시간이며 열차 모드의 재생은 실제 운행 시간과 표시 범위 안으로 제한됩니다. 표시 범위보다 긴 운행의 전체 결과는 표와 CSV에 포함됩니다.

## 계산 범위

현재 엑셀 시간표의 역별 시각 하나를 사용하며 정차 시간을 따로 나누지 않습니다. 실제 철도 곡선 대신 역 좌표 사이 직선으로 진행 방향을 추정합니다. 수서–동탄, 동탄–평택지제는 양방향 항상 ‘해 없음’입니다. 다른 터널, 지형, 건물, 창 구조, 차체 차폐 및 대기굴절은 반영하지 않습니다. ‘해 없음’에는 야간과 지정된 터널 구간이 함께 포함됩니다.

시간표는 사용자 제공 `케택시간표261101.xlsx`에서 추출한 9개 노선 625개 열차 항목입니다. 실시간 운행·운휴 조회 서비스가 아닙니다.

## 데이터 갱신

데스크톱 프로젝트의 시간표·역 좌표·경로 정의를 수정한 뒤 프로젝트 루트에서 다음 명령을 실행합니다.

```powershell
python -B export_web.py
```

생성된 `web/assets`의 파일을 저장소에 다시 올리면 됩니다. 브라우저에 Python이나 엑셀 원본을 전송하지 않습니다.

## 출처

- 지도: 사용자 제공 HAN 고속선 노선도 2024 / 한국철도 철도노선도 2026.01.01. 이미지의 원래 출처 표기를 유지합니다.
- 역 좌표: `assets/station-sources.json`에 원본 출처와 역별 참고 URL을 보존했습니다.
- 태양 계산: 데스크톱 `route_engine.py`와 동일한 NOAA fractional-year 근사식. 일조 방향 분류 및 터널 처리도 동일합니다.
